# 真终端冒烟清单

改了渲染、事件循环、终端外壳之后，在真终端里逐项过一遍：这些东西单元测试验不了。
阶段 2 的验收要求在四种环境里各过一遍：一个 macOS 终端（iTerm2 或 Terminal.app）、tmux、
ssh 到 Linux、Linux 物理控制台或尺寸固定的终端。

```sh
cargo build -p codix
./target/debug/codix --mock                 # 演示 demo；测试场景用 --mock m03-tools 等
./target/debug/codix                        # 真实实例：在一个项目目录里运行
```

## 1. 启动与终端

- [ ] 启动时窗口被请求调到 160×45；终端不支持时按原尺寸显示；退出后恢复原尺寸
- [ ] 在 tmux 里不发尺寸请求（窗口不变）
- [ ] `~/.codix/codix.yaml` 不存在时被生成；改 `ui.theme.preset: aqua` 后主色变水蓝；写错一项时底栏报出来、程序照常起来
- [ ] 中文、emoji、制表符对齐正确，没有错位或残影
- [ ] 拖动窗口改尺寸：宽 ≥ 120 两栏、80–119 单栏、< 60 显示"终端太小"，底栏始终有 `Ctrl+B 切栏 · Ctrl+X 退出 · F1 帮助`

## 2. 实例

- [ ] 实例选择是屏幕中间的小框，新建在第一行，上下键滚动，鼠标单击选中、双击接入
- [ ] 接入被占用的实例要二次确认；`codix --mock default list --all` 列出四种状态

真实实例（第一次执行新编出的二进制，macOS 要先扫描，可能卡十来秒）：

- [ ] 在项目目录里运行 `codix`：没有实例就新建（名字取目录名）并接入；退出选"后台运行"后 `codix list`
      还在、接入者一栏空了；再运行 `codix` 直接接回，之前的会话都在
- [ ] `codix stop <名字>` 之后再在这个目录运行 `codix`，拉起的是原来那个实例，不是 `<名字>-2`
- [ ] 另开一个终端运行 `codix`：提示被占用；选强制接入后，前一个终端显示"被踢"，按任意键可再接回
- [ ] 关掉接着实例的终端窗口（不是退出 TUI）：实例还在，`codix` 能接回
- [ ] 没有凭据时说一句话：转录里显示 `no_credentials` 的错误，界面不卡
- [ ] 有凭据时：流式回答、工具块、权限询问（允许 / 本会话允许 / 拒绝）、AskUserQuestion 的选项、
      子 Agent 出现在会话树、TodoWrite 进 Goal & Todo、`/goal`、`/btw`、`/model`
- [ ] 作业标签 `n`：打开"新作业"的编辑会话；让它建一个每分钟跑一次的作业，作业出现在列表里；
      `R` 立即运行、`空格` 停用、触发记录里有结局和用量

## 3. 对话区（对照 Claude Code）

- [ ] 输入框只有上下两条横线，多行时自动长高；Shift+Enter（或 Alt+Enter / Ctrl+J / `\` 加 Enter）换行
- [ ] `/` 补全、`!` 命令模式、空输入框按 `?` 打开帮助、Shift+Tab 切权限模式
- [ ] 流式回答时状态行 `✻` 动画、秒数、↓ tokens；输入框下显示 `esc 中断`；Esc 中断
- [ ] 工具块 `⏺` / `⎿`、结果折叠与 `ctrl+o 展开`；Ctrl+O 切换详略
- [ ] markdown：标题、列表、表格、引用、代码块语法高亮（「Codix 展示」会话）
- [ ] 审批框：数字 / 上下键 / 鼠标选，Esc 拒绝；正在打字时审批框不抢键盘
- [ ] 粘贴超过 10 行显示 `[粘贴了 N 行]`，提交时展开（需要终端支持 bracketed paste）

## 4. 右栏

- [ ] 会话标签：上下键选主 Agent，左边对话区跟着切；→ 展开 goal / todo；Tab 进下半任务树，选子 Agent 左边跟着切，Esc 回到上一层
- [ ] 对话区顶部面板：有 goal / todo 的会话打开、没有的没有；标题线右边 Ctrl+T，收起后只剩标题线；超过 10 行时 Shift+↑↓ 滚动
- [ ] 会话标签第一行是新建会话；列表里没有流程、作业开出来的会话；焦点在下半时标签头仍是选中色
- [ ] 流程标签：选流程即展开运行，左边是编写会话、面板是流程设计；选运行左边是主会话、面板是运行进度，下半各站不缩进、按进展上色；选「设计」站切到它的独立会话
- [ ] 作业标签：选作业，左边面板是执行情况与统计；下半是定义，流程作业的流程 Enter 跳过去；下半是详情和触发历史，选历史左边跳过去
- [ ] Ctrl+G 依次跳到等你处理的地方；`/` 过滤；F12 事件日志
- [ ] 鼠标：点标签头、点列表、滚轮滚动所在区域、拖动两栏之间的边框调比例；F8 把鼠标交还终端后能用终端原生选择

## 5. 退出

- [ ] Ctrl+X 弹出退出框：后台运行 / 直接退出 / 返回；鼠标也能点
- [ ] 连按两次 Ctrl+C、连按两次 Ctrl+D 也弹出同一个框
- [ ] 退出后终端恢复正常（光标、回显、鼠标、备用屏），没有残留的转义序列

## 6. 环境特有

- [ ] tmux：鼠标、颜色正常；`set-clipboard on` 时 OSC 52 能写剪贴板（P1）
- [ ] ssh：延迟下按键不丢，画面不撕裂
- [ ] 物理控制台 / 固定尺寸：单栏下 Ctrl+B 切过去切得回来，底栏三项始终可见
