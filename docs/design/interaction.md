# Codix 交互规格

本文是阶段 2 mock 验收的依据：每一条都要能在 mock 下操作出来，并且有场景覆盖（场景编号见 `testing.md` §4）。需求编号见 `docs/reqs/codix-requirements.md`。

## 1. 区域与命名

一个区域只有一个名字。三种写法指同一个区域：代码路径用于代码、提交和 bug 报告，中英文用于讨论和清单。代码路径就是 `FrameState` 里的字段路径。

| 代码路径 | English | 中文 |
|---|---|---|
| `header` | Header | 顶栏 |
| `chat` | Chat Pane | 对话区 |
| `chat.crumbs` | Breadcrumbs | 对话·面包屑 |
| `chat.transcript` | Transcript | 对话·转录 |
| `chat.status` | Status Line | 对话·状态行 |
| `chat.composer` | Composer | 对话·输入框 |
| `chat.picker` | Picker | 对话·补全列表（浮在输入框上方） |
| `chat.ask` | Ask Box | 对话·提问框（审批与模型提问，盖在输入框位置） |
| `side` | Side Pane | 右栏 |
| `side.tabs` | Tabs | 右栏·标签头 |
| `side.upper` | Upper List | 右栏·上半 |
| `side.lower` | Lower Tree | 右栏·下半 |
| `footer` | Footer | 底栏（快捷键提示、通知、二次确认） |
| `overlay` | Overlay | 浮层：帮助、表单、查看器，一次只有一个，写作 `overlay:help` 这样的形式 |

## 2. 布局

### 2.1 宽屏（≥ 120 列）：并排

```
┌ Codix  ~/work/auth  code · claude-sonnet-5-5                       ● 已连接 ┐ header
│ 会话 › 重构认证模块 › reviewer            │ [会话 ②]  流程   作业 ①           │ crumbs │ tabs
│                                           │ ▾ ● 重构认证模块         41k tok  │
│ ▌ 帮我把认证迁到 OAuth                     │     goal  迁到 OAuth · 第 2 轮    │ upper
│                                           │     todo  3/7                     │
│ 我先看一下现有的认证入口……                 │ ▸ ○ 昨天的调研             8k tok │
│                                           ├──── 重构认证模块 ─────────────────┤
│ ▸ Read  src/auth/mod.rs          (42 行)   │ ● 主 Agent                       │
│ ▾ Bash  cargo test auth                    │ ▾ ◐ reviewer   子 Agent  12k  2m  │ lower
│   running 18 tests …                       │ │   └ ● cargo test   shell   1m   │
│                                           │ └ ● tail app.log  monitor        │
│ ⠋ 运行中 · 12s · 3.2k tok                  │                                   │ status
│ ╭───────────────────────────────────────╮ │                                   │
│ │ ›                                     │ │                                   │ composer
│ ╰───────────────────────────────────────╯ │                                   │
└ F1 帮助 · F2/F3/F4 标签 · Ctrl+B 右栏 · Ctrl+G 待处理(3)                       ┘ footer
```

- 左右两栏的比例缺省是 60 : 40。焦点在右栏时，用 `<` / `>` 每次调整 5%，范围 40%–75%，调好之后会记住。
- 右栏的上下两段：上半的高度跟着内容走，最多占右栏的一半，下半拿剩下的。
- 右栏收起时（Ctrl+B），对话区占满整个宽度。

### 2.2 窄屏（80–119 列）：单栏

只显示一栏。`Ctrl+B` 在对话区和右栏之间切换。在对话区时，顶栏右侧显示待处理的角标；在右栏时，上下两段占满整个宽度。

### 2.3 更窄（< 80 列或 < 24 行）

照样是单栏，底栏的提示收成最短的形式。宽度低于 60 列时，在中间显示"终端太小"，不做任何渲染。

## 3. 焦点

```
Composer ⇄ Transcript          （对话区内部：Ctrl+↑ / Esc）
   ⇅ Ctrl+O（或 F6）
Side.Upper ⇄ Side.Lower        （右栏内部：Tab）
Dialog（提问框、浮层、二次确认）：模态，只有关掉之后焦点才会回去
```

- 启动时焦点在 Composer。
- 任何地方按 Esc 都是"退一步"，按这个顺序：关浮层或二次确认 → 收起补全列表 → 从右栏回到 Composer → 对话区的上下文退一层（面包屑）。
- 焦点所在的区域边框高亮。底栏的提示随焦点变化。
- 提问框出现时**不抢焦点**：在 Composer 里打字不会被吞掉。按 `Ctrl+O` 或 `Ctrl+G` 才进入提问框。之所以这样设计，是因为旧实现里正在打字时提问框弹出来，接下来敲的 `y` / `n` 就成了回答。

## 4. 对话区

### 4.1 上下文（C-15、F-04、F-07）

| 上下文 | 如何进入 | 输入框 | 面包屑 |
|---|---|---|---|
| 主 Agent 会话 | 在会话标签上半按 Enter；启动时打开最近一个会话或新会话 | 正常对话 | `会话 › <名字>` |
| 子 Agent | 在会话标签下半选中子 Agent 按 Enter | 发出的内容通过"给任务发消息"送达；任务已结束时变成只读 | `会话 › <主> › <子>` |
| 任务输出 | 在下半选中 Shell 或监视器任务按 Enter | 只读，内容实时跟随 | `会话 › <主> › <命令>` |
| 运行主会话 | 在流程标签选中运行按 Enter | 可以插话 | `流程 › <流程> › <主题>` |
| 编写会话 | 在流程标签选中流程定义按 Enter；新建流程 | 正常对话 | `流程 › <流程> › 编写` |

每个上下文各自记住滚动位置、选中的块和折叠状态，切回来时保持原样。

### 4.2 转录

- 块的种类：用户输入（左侧竖条 `▌`）、回答、思考（缺省折叠成一行 `∴ 思考 …`）、工具调用、通知、错误。
- 工具块：头一行是 `▸/▾ 工具名 参数摘要 (结果摘要)`。结果超过 8 行时缺省折叠；修改文件的结果画成 diff（`+` 绿、`-` 红，带行号）。
- 一个块由于 `StepRestarted` 作废时，它的文字直接消失，不留痕迹（C-03）。
- 转录处于贴底状态时自动跟随新内容。往上翻之后停止跟随，底部出现 `↓ 有新内容 (End)`。

### 4.3 状态行

状态行只有一行，各状态互斥：

| 状态 | 显示 |
|---|---|
| 空闲 | 隐藏 |
| 运行中 | `⠋ 运行中 · 12s · 3.2k tok`（spinner 和计时由 Tick 驱动） |
| 等人 | `◐ 等你批准：Bash cargo test`（同时角标 +1） |
| 压缩中 | `⠋ 压缩上下文 …` |
| 已中断 | `■ 已中断`，3 秒后消失 |
| 出错 | `✗ <错误摘要>`，按 Esc 关掉 |
| 断线 | `⚠ 连接断开，重连中 (第 2 次)` |

### 4.4 输入框

- 多行输入，最多占对话区的 1/3 高度，超出部分在框内滚动。
- 运行中按 Enter 是**插话**：消息出现在转录里，标为 `⧗ 待送达`，送达后去掉这个标记。如果被退回（`SteerReturned`），消息回到输入框，并在底栏提示"这条没赶上，已放回输入框"。
- 粘贴超过 10 行时，输入框里显示为 `[粘贴 42 行]` 占位，提交时展开成原文。
- 第一个字符是 `/` 时打开补全列表（4.5）。

### 4.5 slash 命令

| 命令 | 来源 | 作用 |
|---|---|---|
| `/help` | 本地 | 打开帮助浮层 |
| `/new` | 本地 | 新建会话（表单） |
| `/sessions` | 本地 | 焦点跳到会话标签上半 |
| `/model [名字]` | 本地 → 后端 | 不带参数时打开模型选择；以后端的确认为准 |
| `/goal [目标]` | 本地 → 后端 | 设定 goal；不带参数时焦点跳到当前会话的 goal 行 |
| `/btw <问题>` | 本地 → 后端 | 侧问（P1） |
| `/doctor` | 本地 → 后端 | 诊断浮层（P1） |
| `/quit` `/exit` | 本地 | 退出 |
| 其余 | 后端 `Commands{session}` 返回的命令表 | 原样提交 |

补全列表：按前缀过滤，上下键选择，Tab 补全，Enter 提交（已经是完整命令时）。列表最多显示 8 行，每行显示命令名、描述和来源。

### 4.6 提问框（C-04、C-05）

```
╭ 等你批准 (1/3) ── Tab 下一个 ─────────────────────────╮
│ Bash  cargo test --workspace                          │
│ 来自 reviewer（子 Agent）                              │
│ › 1 允许一次                                          │
│   2 本会话总是允许                                     │
│   3 拒绝                                              │
│   4 拒绝并说明理由…                                    │
╰───────────────────────────────────────────────────────╯
```

- 位置：盖在输入框上。输入框里的草稿保留，关掉提问框之后还在。
- 进入：`Ctrl+O` 或 `Ctrl+G`。按键：上下键或数字键选择，Enter 确认，`y` 等于 1，`n` 等于 3，Tab / Shift+Tab 在多个提问之间切换，Esc 退回输入框（不作答，提问仍然挂着）。
- 模型提问：有选项时同上，最后一项是"自己写…"；没有选项时直接给出一个单行输入框。
- 提问来自子 Agent 或流程站时，第二行标出来源。
- `PromptResolved` 到达时（超时、被取消、在别处答过），这一项从队列里消失，底栏提示"已撤回：超时"。

## 5. 右栏

### 5.1 公共键位（焦点在右栏）

| 键 | 动作 |
|---|---|
| ↑ ↓ / `k` `j` | 移动选中 |
| ← → / `h` `l` | 收起 / 展开 |
| Enter | 打开：把选中项驱动到对话区（见 4.1） |
| Tab | 在上半和下半之间切换 |
| `/` | 过滤（按名字） |
| `<` `>` | 调整左右比例 |
| `?` | 当前上下文的帮助 |

**不可逆的操作**（关闭会话、停止任务、取消运行、强制放行、删除作业）在底栏二次确认：`取消运行「…」？ y 确认 / 其他键放弃`。

### 5.2 会话标签（S）

**上半**：主 Agent 列表

```
▾ ● 重构认证模块        ~/work/auth  41k tok
    goal  ◐ 迁到 OAuth，测试全绿 · 第 2/256 轮
    todo  3/7  ✓ 读现有入口  ✓ 设计  ● 实现 provider  ○ …
▸ ◐ 日志巡检            ops-01       12k tok   ← ◐ = 有东西在等你
▸ ○ 昨天的调研          ~/notes       8k tok
```

| 选中 | 键 |
|---|---|
| 会话行 | Enter 打开 · `n` 新建 · `r` 重命名 · `x` 关闭（二次确认） |
| goal 行 | Enter 修改 · `p` 暂停 / 恢复 · `x` 清除（二次确认） |
| todo 行 | → 展开全部条目（只读） |

**下半**：选中主 Agent 的拆分树

```
● 主 Agent                         运行中   2m10s
▾ ◐ reviewer        子 Agent       等你批准  12k  1m40s
│   └ ● cargo test  shell          运行中         1m02s
▸ ✓ researcher      子 Agent       完成      8k   0m50s
└ ● tail app.log    monitor        运行中
```

| 选中 | 键 |
|---|---|
| 子 Agent | Enter 进入它的会话 · `m` 发消息 · `s` 停止（二次确认） |
| Shell / 监视器 / 程序 | Enter 看输出 · `s` 停止（二次确认） |
| 已结束的节点 | 缺省收在 `▸ 已结束 (5)` 下面 |

### 5.3 流程标签（F）

**上半**：流程定义 → 运行

```
▾ 需求到上线  feature-to-ship  内置   2 个在跑
    ● 支付重试   运行中  站 3/5 实现      14m  88k
    ◐ 导出 CSV   等待：待确认  站 4/5 评审  1h  120k
    ✓ 登录限流   已完成                   42m  64k
▸ 周报        weekly-report   用户
```

| 选中 | 键 |
|---|---|
| 流程定义 | Enter 打开编写会话 · `n` 启动一次运行（表单：主题 + 输入参数） · `v` 查看定义（浮层：站列表 + 原始 YAML） |
| 运行 | Enter 打开（对话区切到它的主会话，下半显示各站） · `p` 暂停 / 恢复 · `x` 取消（二次确认） |

**下半**：选中运行的各站

```
✓ 收集需求      session                    3m   12k
✓ 设计          session                    6m   30k
▾ ● 实现        agent × 2                  5m   46k
│   ├ ● 后端    子 Agent  运行中
│   └ ✓ 前端    子 Agent  交付
  ○ 评审        confirm                     待进入
  ○ 上线        gate: ci                    待进入
```

| 选中 | 键 |
|---|---|
| 站 | `c` 确认 · `a` 放行（搁置中的站） · `f` 强制放行（填理由，二次确认） · `r` 返工（选择退回到哪一站） · `t` 重试失败的任务 |
| 站里的任务 | Enter 打开它的会话 |

并行的站排成同一层级，汇合的站在名字后面标 `← 等 a, b`。

### 5.4 作业标签（J）

**上半**：作业

```
● 每日巡检      0 9 * * *     简单  下次 明天 09:00   上次 ✓
● 周报流程      0 10 * * 1    流程  下次 周一 10:00   上次 ✗ 失败
○ 月度归档      0 0 1 * *     流程  已停用
```

**下半**：选中作业的触发历史

```
11-16 09:00  ✓ 完成   2m10s  12k   → 会话「每日巡检 11-16」
11-15 09:00  ✓ 完成   1m55s  11k
11-14 09:00  ✗ 失败   0m12s        provider 返回 429
```

| 选中 | 键 |
|---|---|
| 作业 | `n` 新建 · `e` 编辑（表单） · 空格 启用 / 停用 · `R` 立即运行 · `d` 删除（二次确认） |
| 历史条目 | Enter 跳转到对应的会话或运行 |

作业表单分两类。简单作业：名字、cron、提示词、skills、项目、场景、模型、错过时是否补跑。流程作业：名字、cron、流程、主题模板、输入参数、错过时是否补跑。

## 7. 状态符号

| 符号 | 含义 |
|---|---|
| `●` | 运行中 |
| `◐` | 在等人（审批、确认、搁置、受阻），同时高亮 |
| `○` | 空闲 / 待进入 / 已停用 |
| `✓` | 完成 / 通过 / 交付 |
| `✗` | 失败 / 未达标 |
| `■` | 已停止 / 已取消 |
| `⏸` | 已暂停 / 暂停中 |
| `⊘` | 已跳过 |
| `↺` | 待重做（返工波及） |

颜色只用来加强，不承载信息：去掉颜色之后，靠符号也能读懂。

## 8. 加载、空状态与错误

| 情况 | 显示 |
|---|---|
| 列表加载中 | `加载中 …` 占一行，不阻塞其他区域 |
| 列表为空 | 一行提示 + 下一步怎么做，例如 `还没有流程 · Enter 在对话里设计一个` |
| 命令失败 | 底栏显示错误，按 Esc 关掉；列表上的失败显示 `✗ 加载失败 · r 重试` |
| 能力不可用 | 整个标签只显示一行：`流程不可用：当前连接的是普通 agixd`（R-05） |
| 断线 | 顶栏右侧显示 `⚠ 重连中`，所有列表变灰但保留内容；重连成功后刷新 |

## 9. 帮助浮层

F1 打开，按焦点分组列出：当前上下文的键位、全局键位、slash 命令。内容由键位表生成，不手写，所以不会和实际绑定对不上。
