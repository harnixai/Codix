# Codix 交互规格

这份文档是阶段 2 用 mock 验收的依据。这里写的每一条，都必须能在 mock 下实际操作出来，并且有对应的场景覆盖（场景编号见 `testing.md` §4）。需求编号见 `docs/reqs/codix-requirements.md`。

## 1. 区域与命名

每个区域只有一个名字，下表三列写法都指同一个区域。代码路径用于代码、提交说明和 bug 报告，它就是 `FrameState` 里的字段路径。

| 代码路径 | English | 中文 |
|---|---|---|
| `instances` | Instance Picker | 实例选择（整屏） |
| `header` | Header | 顶栏 |
| `chat` | Chat Pane | 对话区 |
| `chat.crumbs` | Breadcrumbs | 对话·面包屑 |
| `chat.owner` | Ownership Line | 对话·归属行 |
| `chat.transcript` | Transcript | 对话·转录 |
| `chat.status` | Status Line | 对话·状态行 |
| `chat.composer` | Composer | 对话·输入框 |
| `chat.picker` | Picker | 对话·补全列表（浮在输入框上方） |
| `chat.ask` | Ask Box | 对话·提问框（审批与模型提问，盖在输入框的位置上） |
| `divider` | Divider | 分隔线（左右栏之间，可以拖动） |
| `side` | Side Pane | 右栏 |
| `side.tabs` | Tabs | 右栏·标签头 |
| `side.upper` | Upper List | 右栏·上半 |
| `side.lower` | Lower Tree | 右栏·下半 |
| `footer` | Footer | 底栏（快捷键提示、通知、二次确认） |
| `overlay` | Overlay | 浮层：帮助、表单、查看器，同一时间只有一个，写作 `overlay:help` 这种形式 |

## 2. 启动与布局

### 2.1 启动

```
codix ──► 本机有在跑的实例？──否──► 新建实例 ──► 工作台
              │是
              ▼
          实例选择（2.2）──► 接入 / 新建 ──► 工作台
```

**终端尺寸协商（L-06）**：在进入备用屏之前完成。

1. 先请求缺省尺寸（`config.toml` 中的 `ui.initial_size`，缺省值 160×45）。
2. 终端在 300ms 内调整了，就按新尺寸布局；没调整，就按实际尺寸布局。整个过程用户感觉不到。
3. 退出时如果改过尺寸，就请求恢复到原来的尺寸。
4. 以下情况不发起请求：在 tmux 或 screen 里，或者配置成 `off`。

### 2.2 实例选择（I-01）

```
┌ Codix · 选择实例  主机 ops-01 ────────────────────────────────────────┐
│                                                                       │
│  › ● dev        ~/work/auth     运行 3h12m   会话 4   ◐ 等你 2          │
│    ● ops        /srv/ops        运行 6d      会话 9   🔒 me@pts/3 (ssh 10.0.0.7) 空闲 41m │
│    ○ research   ~/notes         已停止（11-14）                          │
│    ✗ old        ~/tmp           残留 · 已清理                            │
│                                                                       │
│    ＋ 新建实例                                                          │
│                                                                       │
└ Enter 接入/启动 · n 新建 · s 停止 · q 退出 · F1 帮助 ───────────────────┘
```

- 每一行都可以用鼠标操作：单击选中，双击接入；已停止的实例双击就是启动。
- **已被接入的实例**（🔒）：会显示接入者（用户、终端、ssh 来源）和已空闲的时长。按 Enter 会提示"已被占用，强制接入会踢掉对方？ y / n"；按 `f` 直接进入强制接入的二次确认。
- 选中"新建实例"并按 Enter，弹出表单：名字（缺省自动生成）、项目（缺省为当前目录）。
- 停止实例需要二次确认。

### 2.3 宽屏（≥ 120 列）：两栏并排

```
┌ Codix  实例 dev@ops-01                                             ● 已连接 ┐ header
│ 会话 › 重构认证模块 › reviewer            ┃ [会话 ②]  流程   作业 ①         │ crumbs │ tabs
│ dev@ops-01 · ~/work/auth · code · sonnet-5-5 · 子 Agent ← 重构认证模块 ┃ ▾ ● 重构认证模块   41k │ owner
│                                           ┃     goal  迁到 OAuth · 第 2 轮  │
│ ▌ 帮我把认证迁到 OAuth                      ┃     todo  3/7                   │ upper
│                                           ┃ ▸ ○ 昨天的调研 ⏰         8k    │
│ 我先看一下现有的认证入口……                  ┣──── 重构认证模块 ──────────────┤
│                                           ┃ ● 主 Agent                     │
│ ▸ Read  src/auth/mod.rs          (42 行)    ┃ ▾ ◐ reviewer  子 Agent 12k 2m   │ lower
│ ▾ Bash  cargo test auth                     ┃ │   └ ● cargo test  shell  1m   │
│   running 18 tests …                        ┃ └ ● tail app.log  monitor      │
│ ⠋ 运行中 · 12s · 3.2k tok                   ┃                                │ status
│ ╭───────────────────────────────────────╮ ┃                                │
│ │ ›                                     │ ┃                                │ composer
│ ╰───────────────────────────────────────╯ ┃                                │
└ F2/F3/F4 标签 · Ctrl+G 待处理(3) · F8 鼠标  ·  Ctrl+B 切栏 · F1 帮助       ┘ footer
```

- 左右两栏缺省比例 60 : 40。调整方式：拖动分隔线 `┃`；或者焦点在右栏时按 `<` / `>`，每次 5%。可调范围 40%–75%，调过之后会记住。
- 右栏分上下两段，上半的高度跟内容走，最多占右栏的一半。
- 按 Ctrl+B 收起右栏，对话区占满整个宽度。

### 2.4 窄屏（80–119 列）与尺寸固定的终端：单栏

- 同一时间只显示一栏，**Ctrl+B 在对话区和右栏之间切换**。
- 显示对话区时，顶栏右侧标出右栏的待处理角标；显示右栏时，上下两段都占满整宽。
- **底栏最右边永远有 `Ctrl+B 切栏 · F1 帮助`**（L-07），在任何焦点、任何浮层、任何二次确认里都显示，保证在物理控制台这类尺寸不能调的终端上，切过去之后一定切得回来。
- 底栏空间不够时，从左边开始砍提示，这两项永远保留。

### 2.5 极窄（< 80 列或 < 24 行）

仍然是单栏，底栏只保留那两项。宽度不到 60 列时，屏幕中间只显示"终端太小（需要至少 60 列）"，底栏照常显示。

## 3. 焦点

```
Composer ⇄ Transcript           （对话区内部：Ctrl+↑ / Esc，或者鼠标点击）
   ⇅ Ctrl+O（或 F6、鼠标点击）
Side.Upper ⇄ Side.Lower         （右栏内部：Tab，或者鼠标点击）
Dialog（提问框、浮层、二次确认）：模态，必须先关掉才能把焦点移走
```

- 启动后焦点在 Composer。
- 任何地方按 Esc 都是"退一步"，顺序是：关浮层或二次确认 → 收起补全列表 → 从右栏回到 Composer → 对话区的上下文退一层。
- 有焦点的区域边框高亮，底栏的提示随焦点切换。
- **提问框弹出时不抢焦点。** 如果正在打字，后面敲的键不会被当成对提问的回答。要按 Ctrl+O、Ctrl+G，或者直接用鼠标点提问框，才会进入它。

## 4. 对话区

### 4.1 上下文与归属（C-12、C-16、F-04、F-07）

| 上下文 | 怎么进入 | 输入框 | 面包屑 |
|---|---|---|---|
| 主 Agent 会话 | 会话标签上半按 Enter 或双击；启动时打开最近一个 | 正常对话 | `会话 › <名字>` |
| 子 Agent | 会话标签下半选中后按 Enter 或双击 | 消息经"给任务发消息"送到它；任务已结束则只读 | `会话 › <主> › <子>` |
| 任务输出 | 下半选中 Shell 或监视器任务后按 Enter | 只读，实时跟随 | `会话 › <主> › <命令>` |
| 运行主会话 | 流程标签里选中一次运行后按 Enter | 可以插话 | `流程 › <流程> › <主题>` |
| 编写会话 | 流程标签里选中流程定义后按 Enter；新建流程 | 正常对话 | `流程 › <流程> › 编写` |

**归属行**（`chat.owner`）就在面包屑下面，格式是：

```
<实例>@<主机> · <项目> · <场景> · <模型> · <来源>
```

`<来源>` 有以下几种：

- `用户新建`
- `作业「每日巡检」11-16 09:00`
- `流程「需求到上线」› 支付重试 › 实现`
- `子 Agent ← <上级会话>`
- `分叉自 <会话>`

宽度不够时从右往左截断，`<实例>@<主机>` 始终保留。会话在另一个实例里被打开（被占用）时，归属行末尾标上 `⚠ 被实例 <名字> 占用`，同时输入框变成只读。

每个上下文各自记住滚动位置、选中的块、折叠状态。

### 4.2 转录

- 块的种类：用户输入（左边带竖条 `▌`）、回答、思考（缺省折成一行 `∴ 思考 …`）、工具调用、通知、错误。
- 工具块的头一行是 `▸/▾ 工具名 参数摘要 (结果摘要)`。结果超过 8 行时缺省折叠。修改文件的结果显示成 diff：`+` 绿色，`-` 红色，带行号。
- 一个块因为 `StepRestarted` 作废时，直接消失，不留痕迹（C-03）。
- 转录在最底部时自动跟随新内容。往上翻之后停止跟随，底部出现 `↓ 有新内容 (End)`，可以点。

### 4.3 状态行

状态行只有一行，以下状态互斥：

| 状态 | 显示 |
|---|---|
| 空闲 | 隐藏 |
| 运行中 | `⠋ 运行中 · 12s · 3.2k tok` |
| 等人 | `◐ 等你批准：Bash cargo test` |
| 压缩中 | `⠋ 压缩上下文 …` |
| 已中断 | `■ 已中断`，3 秒后消失 |
| 出错 | `✗ <错误摘要>`，按 Esc 关掉 |
| 断线 | `⚠ 与实例断开，重连中 (第 2 次)` |

### 4.4 输入框

- 支持多行，最多占对话区的 1/3 高度，超出后在框内滚动。
- 运行中按 Enter 是**插话**：这条消息在转录里标为 `⧗ 待送达`，送达后标记去掉。被退回时，消息放回输入框，底栏提示一句。
- 一次粘贴超过 10 行时，输入框里显示 `[粘贴 42 行]` 占位，提交时展开成原文。
- 第一个字符是 `/` 时弹出补全列表。

### 4.5 slash 命令

| 命令 | 来源 | 作用 |
|---|---|---|
| `/help` | 本地 | 打开帮助浮层 |
| `/new` | 本地 | 新建会话（弹表单） |
| `/sessions` | 本地 | 焦点跳到会话标签的上半 |
| `/model [名字]` | 本地 → 后端 | 不带参数时打开模型选择；切换结果以后端确认为准 |
| `/goal [目标]` | 本地 → 后端 | 设定 goal；不带参数时焦点跳到 goal 行 |
| `/btw <问题>` | 本地 → 后端 | 侧问（P1） |
| `/doctor` | 本地 → 后端 | 诊断浮层（P1） |
| `/quit` `/exit` | 本地 | **脱离**：TUI 退出，实例继续运行 |
| `/stop` | 本地 → 后端 | 停止实例（需二次确认），然后退出 |
| 其余命令 | 后端 `Commands{session}` 给出的命令表 | 原样提交 |

补全列表：按前缀过滤，上下键或鼠标选择，Tab 补全，Enter 提交（命令已经完整时）。最多显示 8 行，每行显示命令名、描述、来源。

### 4.6 提问框（C-04、C-05）

```
╭ 等你批准 (1/3) ── Tab 下一个 ─────────────────────────╮
│ Bash  cargo test --workspace                          │
│ 来自 reviewer（子 Agent）                              │
│ › 1 允许一次                                          │
│   2 本会话总是允许                                     │
│   3 拒绝                                              │
│   4 拒绝并说明理由…                                    │
╰───────────────────────────────────────────────────────╯
```

- 盖在输入框上面，输入框里的草稿保留。
- 进入方式：Ctrl+O、Ctrl+G，或者鼠标点击。
- 操作：上下键或数字键选择，Enter 确认，也可以直接单击某个选项（单击即确认）。快捷键 `y` 等同于 1，`n` 等同于 3。Tab / Shift+Tab 在多个提问之间切换。Esc 退回输入框，不作答，提问继续挂着。
- 模型提问：有选项时同上，最后一项是"自己写…"；没有选项时直接显示一个单行输入框。
- 提问来自子 Agent 或流程中的某一站时，第二行写明来源。
- 收到 `PromptResolved`（超时、被取消、流程按策略代答）时，这个提问从队列里消失，底栏提示原因。

## 5. 右栏

### 5.1 通用操作

| 键盘 | 鼠标 | 动作 |
|---|---|---|
| ↑ ↓ / `k` `j` | 单击 | 移动选中 |
| ← → / `h` `l` | 点击 `▸` `▾` | 收起 / 展开 |
| Enter | 双击 | 打开：把选中项驱动到对话区（见 4.1） |
| Tab | 点击上半或下半 | 在上半和下半之间切换 |
| `/` | | 按名字过滤 |
| `<` `>` | 拖动分隔线 | 调整左右比例 |
| | 滚轮 | 滚动鼠标所在的那一段 |
| `?` | | 当前上下文的帮助 |

**不可逆操作**在底栏做二次确认：`取消运行「…」？ y 确认 / 其他键放弃`。确认这一步也可以用鼠标点 `[确认]` / `[放弃]`。

### 5.2 会话标签

**上半**：主 Agent 列表，每行末尾用图标标出来源（⏰ 作业、⇶ 流程、⑂ 分叉，用户新建的不标）。

```
▾ ● 重构认证模块        ~/work/auth  code   41k tok
    goal  ◐ 迁到 OAuth，测试全绿 · 第 2/256 轮
    todo  3/7  ✓ 读现有入口  ✓ 设计  ● 实现 provider  ○ …
▸ ◐ 日志巡检            /srv/ops     ops    12k tok  ⏰
▸ ○ 昨天的调研          ~/notes      code    8k tok
```

| 选中的行 | 操作 |
|---|---|
| 会话 | Enter 打开 · `n` 新建 · `r` 重命名 · `x` 关闭（需二次确认） |
| goal | Enter 修改 · `p` 暂停 / 恢复 · `x` 清除（需二次确认） |
| todo | → 展开全部条目（只读） |

**下半**：选中主 Agent 的拆分树

```
● 主 Agent                         运行中   2m10s
▾ ◐ reviewer        子 Agent       等你批准  12k  1m40s
│   └ ● cargo test  shell          运行中         1m02s
▸ ✓ researcher      子 Agent       完成      8k   0m50s
└ ● tail app.log    monitor        运行中
```

| 选中的节点 | 操作 |
|---|---|
| 子 Agent | Enter 进入它的会话 · `m` 发消息 · `s` 停止（需二次确认） |
| Shell / 监视器 / 程序 | Enter 查看输出 · `s` 停止（需二次确认） |
| 已结束的 | 缺省收在 `▸ 已结束 (5)` 下面 |

### 5.3 流程标签

**上半**：流程定义 → 运行

```
▾ 需求到上线  feature-to-ship  内置   2 个在跑
    ● 支付重试   运行中  站 3/5 实现      14m  88k
    ◐ 导出 CSV   等待：待确认  站 4/5 评审  1h  120k
    ✓ 登录限流   已完成                   42m  64k
▸ 周报        weekly-report   用户
```

| 选中的行 | 操作 |
|---|---|
| 流程定义 | Enter 打开编写会话 · `n` 启动一次运行（表单） · `v` 查看定义（浮层） |
| 运行 | Enter 打开 · `p` 暂停 / 恢复 · `x` 取消（需二次确认） |

**下半**：选中那次运行的各站

```
✓ 收集需求      session                    3m   12k
✓ 设计          session                    6m   30k
▾ ● 实现        agent × 2                  5m   46k
│   ├ ● 后端    子 Agent  运行中
│   └ ✓ 前端    子 Agent  交付
  ○ 评审        confirm                     待进入
  ○ 上线        gate: ci                    待进入
```

| 选中的行 | 操作 |
|---|---|
| 站 | `c` 确认 · `a` 放行（搁置中的站） · `f` 强制放行（要填理由，需二次确认） · `r` 返工（选择退回到哪一站） · `t` 重试失败的任务 |
| 站里的任务 | Enter 打开对应会话 |

并行的站排在同一层级；汇合的站在名字后面标 `← 等 a, b`。

### 5.4 作业标签

**上半**：作业

```
● 每日巡检      0 9 * * *     简单  下次 明天 09:00   上次 ✓
● 周报流程      0 10 * * 1    流程  下次 周一 10:00   上次 ✗ 失败
○ 月度归档      0 0 1 * *     流程  已停用
```

**下半**：选中作业的触发历史

```
11-16 09:00  ✓ 完成   2m10s  12k   → 会话「每日巡检 11-16」
11-15 09:00  ✓ 完成   1m55s  11k
11-14 09:00  ✗ 失败   0m12s        provider 返回 429
```

| 选中的行 | 操作 |
|---|---|
| 作业 | `n` 新建 · `e` 编辑 · 空格（或点击 ●/○）启用 / 停用 · `R` 立即运行 · `d` 删除（需二次确认） |
| 历史条目 | Enter 或双击，跳到对应的会话或运行 |

作业表单有两种：

- **简单作业**：名字、cron、提示词、skills、项目、场景、模型、错过的触发要不要补跑。
- **流程作业**：名字、cron、流程、主题模板、输入参数、错过的触发要不要补跑。

## 6. 鼠标（M）

| 位置 | 单击 | 双击 | 拖动 | 滚轮 |
|---|---|---|---|---|
| 标签头 | 切换标签 | | | |
| 列表行 / 树节点 | 选中，同时获得焦点 | 打开（等同 Enter） | | 滚动这一段 |
| `▸` `▾` | 展开 / 收起 | | | |
| 工具块的头一行 | 展开 / 收起 | | | |
| 转录正文 | 焦点切到转录 | | 选择文字，松开时复制（OSC 52，M-07，P1） | 滚动转录 |
| 输入框 | 获得焦点，移动光标 | 选中一个词 | | |
| 提问框选项、表单按钮、二次确认按钮 | 选中并确认 | | | |
| 分隔线 `┃` | | | 调整左右比例 | |
| `↓ 有新内容` | 回到底部，继续跟随 | | | |

- **F8**（替代键 Alt+M）切换鼠标捕获。关掉之后鼠标交还给终端，可以用终端原生的方式选择、复制。底栏显示 `鼠标：终端`，再按一次恢复。
- 不关捕获时，大多数终端按住 Shift（macOS 上是 Option）拖动，也能做原生选择。这一点写进帮助浮层。
- 所有鼠标操作都会翻译成和键盘相同的动作，没有只有鼠标才能触发的功能。

## 7. 全局键位

| 键 | 动作 | 替代 |

## 8. 状态符号

| 符号 | 含义 |
|---|---|
| `●` | 运行中 |
| `◐` | 在等人（审批、确认、搁置、受阻），同时高亮 |
| `○` | 空闲 / 待进入 / 已停用 / 已停止（实例） |
| `✓` | 完成 / 通过 / 交付 |
| `✗` | 失败 / 未达标 / 残留（实例） |
| `■` | 已停止 / 已取消 |
| `⏸` | 已暂停 / 暂停中 |
| `⊘` | 已跳过 |
| `↺` | 待重做 |
| `⏰` `⇶` `⑂` | 会话来源：作业 / 流程 / 分叉 |

颜色只起加强作用，不单独承载信息：去掉颜色，只看符号也能读懂。

## 9. 加载、空状态与错误

| 情况 | 显示 |
|---|---|
| 列表正在加载 | 一行 `加载中 …`，不阻塞其他区域 |
| 列表为空 | 一行提示，并说明下一步可以做什么，例如 `还没有流程 · Enter 在对话里设计一个` |
| 命令失败 | 底栏显示错误，Esc 关掉；列表加载失败时显示 `✗ 加载失败 · r 重试` |
| 会话被别的实例占用 | 见 4.1 |
| 与实例断开 | 顶栏显示 `⚠ 重连中`，所有列表变灰但保留内容；重连成功后刷新 |
| 实例被停止（被别处停掉，或进程崩溃） | 回到实例选择界面，并提示原因 |
| 被强制接入的一方踢掉 | 进入"已脱离"界面：`已被 me@pts/5 (ssh 10.0.0.9) 于 14:02 强制接入`。按 Enter 回到实例选择，按 q 退出 |
| 空闲超时 | 进入"已脱离"界面：`空闲 30 分钟，已自动脱离，实例仍在运行`。按任意键重新接入；如果这时实例已被别人接入，就按占用处理 |
